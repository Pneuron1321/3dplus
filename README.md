# PIXEL MECH™ — модульный коллекционный

Фигурка из кирпичиков: пиксельное лицо, красный зеркальный щиток-очки, фиолетовый 8-битный пришелец на шапке-черепе, атлетичное тело с наплечниками и наручами и спортивные ступни-кроссовки. Версия 5 собрана по заданию [`docs/PROMPT-v5.md`](docs/PROMPT-v5.md): голова — по первому листу-образцу (как в v4), тело — по второму изображению заказчика (лист 2). Сверка с листами — по метрикам.

## Что изменилось в v5

- **Тело длиннее и «фит»**: голова поднята на 3.5 (низ 17.0 → 20.5), ноги получили бедро, колено и голень, фигурка теперь 31.1 в высоту.
- **Корпус с V-силуэтом**: белая грудь ±4.75 со скошенными рёбрами, «шевронами» и швом, серый и тёмный пояса, живот сужается до ±3.35, **таз — отдельный модуль**.
- **Руки из сегментов** вместо кулаков-кубов: наплечник (тёмная половина с крупными шипами, белая, оранжевая кромка), локоть, наруч с шипами 2 × 3 и оранжевой накладкой со ступицей, кулак из трёх пальцев.
- **Ступни-кроссовки**: длина 10.4 → 8.0, основной объём 3.6 → 2.8 в высоту; жёлтая подошва, тёмная полоса, носок-клин, «шнуровка» из шипов, косая спортивная полоса, задник и высокий манжет голеностопа с двумя парами болтов.
- Голова не менялась: её геометрия и цвета совпадают с v4 побайтно, поэтому её сверка с листом 1 (очки 13.2 и т. д.) остаётся в силе.

## Сверка тела с листом 2 (`tools/qa_body.py`)

Лист и рендер переносятся в мировые единицы (лист — по замеру 22 px на единицу, рендер — по проекциям опорных точек), сравнивается тело ниже шеи. Обе версии отрендерены одной камерой сверки.

| Метрика | v4 | **v5** |
|---|---|---|
| Тело спереди: IoU силуэта | 0.610 | **0.842** |
| Срезы ширины с ошибкой > 1.2 ед. (из 20) | 15 | **4** |
| Средний ΔE по 22 цветовым зонам тела | 40.6 | **7.1** |
| Худшая зона, ΔE | 88.9 | 34.7 (подошва — см. ниже) |
| ΔE по всей картинке тела | 33.0 | **17.1** |
| 3/4: IoU силуэта тела | 0.685 | **0.835** |
| Ступня: длина | 10.4 | **8.0** |
| Ступня: рамка с болтами (ш × в × д) | 7.3 × 6.4 × 10.4 | **7.1 × 6.0 × 8.0** (объём −30 %) |

Худшая зона — подошва: носок ступни стоит на 5 единиц ближе к камере, чем плоскость сравнения, и на месте жёлтой подошвы листа у модели оказывается полоса и верх. Сама подошва жёлтая (#fdb635, как на листе). Узкие ступни и низкий верх — сознательное отличие от листа 2: заказчик просил ступни меньше и спортивнее, а на листе они ещё длиннее, чем были в v4.

```bash
node tools/build.mjs --view=qa && python3 tools/qa_body.py <лист-2.jpg>      # тело, вид спереди
python3 tools/qa.py <лист-образец.jpg>                                        # вся фигура по листу 1 (как в v4)
```

## Файлы

| Файл | Что это |
|---|---|
| `pixel-mech.glb` | модель glTF 2.0 (≈6.5 МБ, ≈156 тыс. вершин, высота ≈31.1 единицы): цвета и затенение в вершинах, детали — отдельными узлами |
| `index.html` | интерактивный вьювер: вращение, мимика, разобранный вид с подписями и значками магнитов, снимок PNG, выгрузка GLB |
| `src/pixel-mech.js` | генератор модели (three.js r128) — единственный источник геометрии |
| `tools/build.mjs`, `tools/render.html` | сборка: рендеры для листа в `renders/` (суперсэмплинг ×2) и экспорт `pixel-mech.glb` |
| `tools/qa_body.py` | сверка тела с листом 2 в мировых единицах: IoU, 20 срезов ширины, 22 цветовые зоны, ΔE по картинке |
| `tools/qa.py` | сверка с листом-образцом 1 (голова и вся фигура v4): силуэт, срезы, цвета по зонам, очки по точкам |
| `docs/PROMPT-v5.md` | задание v5: замеры тела с листа 2, решения по ступням, целевые размеры, палитра, критерии приёмки, итоги |
| `docs/PROMPT-v3.md` | задание v3 и итерация v4: голова, очки, свет — по листу 1 |
| `renders/` | рендеры ракурсов листа (вид спереди, 3/4, детали, модули, разобранный вид) |

## Как смотреть

Открой `index.html` в браузере (нужен интернет для three.js с CDN). Если браузер не грузит скрипт с диска, подними локальный сервер: `npx serve .` и открой адрес из консоли.

`pixel-mech.glb` открывается в Blender (Файл → Импорт → glTF 2.0), Godot, Unity (glTFast) и в онлайн-просмотрщиках.

## Как пересобрать

```bash
npm install
npm run build        # рендеры + pixel-mech.glb
npm run renders      # только картинки
node tools/build.mjs --view=front,three4   # отдельные ракурсы
node tools/build.mjs --view=qa             # камера сверки для tools/qa_body.py (в git не входит)
```

Нужен Chromium: скрипт берёт его из `CHROME_PATH`, `PLAYWRIGHT_BROWSERS_PATH` или обычной установки Playwright.

## Устройство модели

Масштаб: шаг шипа 0.8, пол — `y = 0`, лицом к `+z`. Высота до шипов рожек пришельца — около 31.1. Свет студии падает справа-спереди, как на листе.

Каждая деталь — воксельная сетка со своим шагом клетки. Видимые клетки превращаются в кирпичи 1×1…1×6 с перевязкой рядов, фаской и небольшим разбросом тона. Клетка может быть скосом: коробка, отсечённая плоскостями, — так сделаны скошенные рёбра груди, скруглённые наплечники и наручи, носок и задник кроссовок, верх шапки и боковых плит. За каждым кирпичом стоит тёмная подложка, поэтому швы читаются как настоящие зазоры. Затенение в углах (AO) запекается в цвета вершин по заполненности соседних клеток — только внутри детали, чтобы в разобранном виде ничего не пачкалось. Шипы точёные, в том числе боковые. Техник-втулки, штифты, болты-оси, шея, очки и магнитные шайбы на стыках — отдельная геометрия.

| Узел | Деталь | Как сделано |
|---|---|---|
| `shapka` | шапка-череп | два слоя макро-кирпичей 1.6 с крупными шипами (как на панели HEAD TOP), углы скруглены, сзади тёмный скос; пришелец 8 × 6 — кирпич и гладкая плитка сверху, рожки-столбики с шипом, глазницы — утопленные чёрные плитки |
| `ochki` | очки | щиток по пологой дуге с поворотом к вискам, вырез переносицы, тёмно-красная тонировка; блики — только отражение отдельного окружения (две красные полосы), поэтому середина и глаза тёмные |
| `lico` | лицевая панель | жёлтая кладка рядами 0.512, под линзой длинные кирпичи, нижний ряд утоплен; глаза и 8-битный рот — отдельные плитки для мимики |
| `bokL`, `bokR` | боковые плиты | толщина 1.25, скруглённый верх, тёмный торец со светлыми шипами вперёд, крупные шипы вбок, техник-кирпич с двумя отверстиями, шарнир дужки, оранжевое ухо сзади |
| `sheya` | шея-штырь | воронёный ПВХ: воротник с винтами, штырь с канавкой |
| `korpus` | корпус | грудь 10 × 5 × 6 клеток (±4.75 × 15.1…19.5): белая кладка, скошенные передние рёбра, верхние углы уходят внутрь с тёмными «кнопками», два наклонных шеврона с шипами, чёрный шов; серый пояс с тёмными шипами, тёмный пояс, живот ±3.35; гнездо шеи, плечевые шарниры |
| `taz` | таз | блок ±2.0 (11.3…12.3), тёмно-коричневая промежность до 9.9, гнёзда бёдер по бокам — отдельный модуль разлёта |
| `rukaL`, `rukaR` | руки | наплечник 4.0 × 3.5 × 3.8 (тёмная внутренняя половина с двумя крупными шипами, белая наружная со скруглённым верхом, оранжевая кромка сзади, чуть опущен наружу), тёмный локоть с осью; наруч `_naruch` 4.0 × 4.4 × 4.0 со скруглёнными рёбрами, шипами 2 × 3 спереди, оранжевой накладкой и ступицей снаружи; кулак — три пальца и большой палец |
| `nogaL`, `nogaR` | ноги | бедро 3.6 × 3.4 × 3.0 (светлый верх с тёмными шипами, шипы вперёд, оранжевая пластина снаружи, тёмная ступица с болтом внутрь), серый наколенник и тёмный шарнир с осью и оранжевым кольцом; голень `_golen` — мелкая кладка 2.8 × 4.4, отведена наружу, с осью голеностопа |
| `stupnyaL`, `stupnyaR` | ступни | кроссовок 7 × 10 шипов (5.6 × 8.0): протектор и жёлтая подошва, тёмная полоса, оранжевый верх с носком-клином, шипы-«шнуровка», косая полоса по бокам, задник с язычком, манжет голеностопа до 5.8 с двумя парами болтов |

Материалы в GLB: `abs_plastic` (матовый, цвета вершин), `black_tile`, `gunmetal`, `sunglass_lens` (прозрачный, с градиентом), `sunglass_frame`. Во вьювере линза рисуется как тонировка умножением плюс зеркальные блики — глаза видны сквозь красный, как на листе.
