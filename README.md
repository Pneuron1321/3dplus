# PIXEL MECH™ — модульный коллекционный

Фигурка из кирпичиков: пиксельное лицо, красный зеркальный щиток-очки, фиолетовый 8-битный пришелец на шапке-черепе, кулаки-блоки со скосами и ступенчатые оранжевые ступни с болтами-осями. Версия 4 собрана по заданию [`docs/PROMPT-v3.md`](docs/PROMPT-v3.md) (раздел 12 — итерация v4) и сверена с листом-образцом по метрикам в двух ракурсах.

## Сверка с листом-образцом (`tools/qa.py`)

Обе версии отрендерены одинаковыми камерами (спереди — наклон 0.18; 3/4 — поворот 0.42, наклон 0.18).

| Метрика | v3 | **v4** |
|---|---|---|
| Вид спереди: IoU силуэтов | 0.868 | **0.868** |
| Вид спереди: срезы ширины с ошибкой > 6 % (из 24) | 5 | 7 |
| Вид спереди: средний ΔE по 17 цветовым зонам | 5.6 | **5.6** |
| Вид спереди: ΔE по всей картинке (свет, контраст, раскладка цветов) | 17.7 | **16.8** |
| Очки и глаза: ΔE в 8 точках (глаза сквозь линзу, блики, середина) | 28.4 | **13.2** |
| 3/4: IoU силуэтов | 0.848 | 0.833 |
| 3/4: ΔE по всей картинке | 22.0 | 23.1 |

Силуэт по цифрам почти не изменился: v4 правил в основном форму деталей, свет и цвет, а их IoU не ловит. Сильнее всего улучшились очки (глаза стали почти чёрными, как на листе, появились две полосы бликов) и общий цвет и свет вида спереди. Ракурс 3/4 на листе не согласован с видом спереди (он нарисован нейросетью), поэтому пропорции подгонялись по виду спереди, а 3/4 немного просел.

```bash
python3 tools/qa.py <лист-образец.jpg>                                # вид спереди
python3 tools/qa.py <лист-образец.jpg> renders/three4.png --view=three4
```

## Файлы

| Файл | Что это |
|---|---|
| `pixel-mech.glb` | модель glTF 2.0 (≈6.3 МБ, ≈156 тыс. вершин, высота ≈27.6 единиц): цвета и затенение в вершинах, детали — отдельными узлами |
| `index.html` | интерактивный вьювер: вращение, мимика, разобранный вид с подписями и значками магнитов, снимок PNG, выгрузка GLB |
| `src/pixel-mech.js` | генератор модели (three.js r128) — единственный источник геометрии |
| `tools/build.mjs`, `tools/render.html` | сборка: рендеры для листа в `renders/` (суперсэмплинг ×2) и экспорт `pixel-mech.glb` |
| `tools/qa.py` | сверка рендера с листом-образцом: силуэт, срезы ширины, цвета по зонам, очки по точкам, оба ракурса |
| `docs/PROMPT-v3.md` | задание: замеры с листа, целевые размеры, палитра, критерии приёмки; раздел 12 — что нашла и исправила итерация v4 |
| `renders/` | рендеры ракурсов листа (вид спереди, 3/4, детали, модули, разобранный вид) |

## Как смотреть

Открой `index.html` в браузере (нужен интернет для three.js с CDN). Если браузер не грузит скрипт с диска, подними локальный сервер: `npx serve .` и открой адрес из консоли.

`pixel-mech.glb` открывается в Blender (Файл → Импорт → glTF 2.0), Godot, Unity (glTFast) и в онлайн-просмотрщиках.

## Как пересобрать

```bash
npm install
npm run build        # рендеры + pixel-mech.glb
npm run renders      # только картинки
node tools/build.mjs --view=front,three4   # отдельные ракурсы
```

Нужен Chromium: скрипт берёт его из `CHROME_PATH`, `PLAYWRIGHT_BROWSERS_PATH` или обычной установки Playwright.

## Устройство модели

Масштаб: шаг шипа 0.8, пол — `y = 0`, лицом к `+z`. Высота до шипов рожек пришельца — около 27.6. Свет студии падает справа-спереди, как на листе.

Каждая деталь — воксельная сетка со своим шагом клетки. Видимые клетки превращаются в кирпичи 1×1…1×6 с перевязкой рядов, фаской и небольшим разбросом тона. Клетка может быть скосом: коробка, отсечённая плоскостями, — так сделаны срезанные углы кулаков, скруглённая кромка ступней, верх шапки и боковых плит. За каждым кирпичом стоит тёмная подложка, поэтому швы читаются как настоящие зазоры. Затенение в углах (AO) запекается в цвета вершин по заполненности соседних клеток — только внутри детали, чтобы в разобранном виде ничего не пачкалось. Шипы точёные, в том числе боковые. Техник-втулки, штифты, болты-оси, шея, очки и магнитные шайбы на стыках — отдельная геометрия.

| Узел | Деталь | Как сделано |
|---|---|---|
| `shapka` | шапка-череп | два слоя макро-кирпичей 1.6 с крупными шипами (как на панели HEAD TOP), углы скруглены, сзади тёмный скос; пришелец 8 × 6 — кирпич и гладкая плитка сверху, рожки-столбики с шипом, глазницы — утопленные чёрные плитки |
| `ochki` | очки | щиток по пологой дуге с поворотом к вискам, вырез переносицы, тёмно-красная тонировка; блики — только отражение отдельного окружения (две красные полосы), поэтому середина и глаза тёмные |
| `lico` | лицевая панель | жёлтая кладка рядами 0.512, под линзой длинные кирпичи, нижний ряд утоплен; глаза и 8-битный рот — отдельные плитки для мимики |
| `bokL`, `bokR` | боковые плиты | толщина 1.25, скруглённый верх, тёмный торец со светлыми шипами вперёд, крупные шипы вбок, техник-кирпич с двумя отверстиями, шарнир дужки, оранжевое ухо сзади |
| `sheya` | шея-штырь | воронёный ПВХ: воротник с винтами, штырь с канавкой |
| `korpus` | корпус | таз ±3.7 с гнёздами бёдер и чёрными штифтами, тёмный пояс, грудь 6 × 2 макро-блока (4 крупных шипа, белая середина, скошенные углы с шипами), верх с шипами вокруг гнезда шеи, тёмные плечевые блоки с чёрными штырями, светлые оси |
| `rukaL`, `rukaR` | руки | кулак-блок 3 × 5 × 3 макро-клеток 1.4 со скосами на углах, крупным шипом на каждой клетке и тёмными костяшками; поза подобрана перебором по силуэтам обоих ракурсов |
| `nogaL`, `nogaR` | ноги | один наклонный блок: тёмный верх, средне-серая мелкая кладка; ось бедра и ось голеностопа с хромированным стержнем |
| `stupnyaL`, `stupnyaR` | ступни | 7 × 13: основание (два высоких кирпича по центру, стопки плит по бокам), средний ярус из плит, верхний из четырёх кирпичей со скруглённой кромкой, узкая подкова вокруг голени, тонкие стойки вилки, четыре болта |

Материалы в GLB: `abs_plastic` (матовый, цвета вершин), `black_tile`, `gunmetal`, `sunglass_lens` (прозрачный, с градиентом), `sunglass_frame`. Во вьювере линза рисуется как тонировка умножением плюс зеркальные блики — глаза видны сквозь красный, как на листе.
