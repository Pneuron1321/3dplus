# PIXEL MECH™ — модульный коллекционный

Фигурка из кирпичиков: пиксельное лицо, красный зеркальный щиток-очки, фиолетовый 8-битный пришелец на шапке-черепе, кулаки-блоки со скосами и ступенчатые оранжевые ступни с болтами-осями. Версия 3 собрана по заданию [`docs/PROMPT-v3.md`](docs/PROMPT-v3.md) и сверена с листом-образцом по метрикам.

## Сверка с листом-образцом (вид спереди, `tools/qa.py`)

| Метрика | v2 | **v3** | Цель |
|---|---|---|---|
| IoU силуэтов | 0.775 | **0.872** | ≥ 0.86 |
| Срезы ширины с ошибкой > 6 % кадра (из 24) | 16 | **3** | ≤ 5 |
| Средний ΔE по 17 цветовым зонам | 24.9 | **5.4** | ≤ 8 |
| Худший ΔE по зоне | 83.8 | **11.3** | ≤ 15 |

Как считается: силуэт фигуры выделяется по голубому фону, обе картинки приводятся к одной высоте и центрируются по голове; ширина сравнивается в 24 горизонтальных срезах; цвет — медиана в зонах, заданных в мировых единицах (лицо, линза, шапка, пришелец, ухо, грудь, пояс, таз, плечо, кулак, голень, три яруса ступни, шея), разница — ΔE CIE76.

## Файлы

| Файл | Что это |
|---|---|
| `pixel-mech.glb` | модель glTF 2.0 (≈7.3 МБ, ≈174 тыс. вершин, высота 28 единиц): цвета и затенение в вершинах, детали — отдельными узлами |
| `index.html` | интерактивный вьювер: вращение, мимика, разобранный вид с подписями и значками магнитов, снимок PNG, выгрузка GLB |
| `src/pixel-mech.js` | генератор модели (three.js r128) — единственный источник геометрии |
| `tools/build.mjs`, `tools/render.html` | сборка: рендеры для листа в `renders/` (суперсэмплинг ×2) и экспорт `pixel-mech.glb` |
| `tools/qa.py` | сверка рендера с листом-образцом: силуэт, срезы ширины, цвета по зонам |
| `docs/PROMPT-v3.md` | задание v3: замеры с листа, целевые размеры, палитра, критерии приёмки |
| `renders/` | рендеры ракурсов листа (вид спереди, 3/4, детали, модули, разобранный вид) |

## Как смотреть

Открой `index.html` в браузере (нужен интернет для three.js с CDN). Если браузер не грузит скрипт с диска, подними локальный сервер: `npx serve .` и открой адрес из консоли.

`pixel-mech.glb` открывается в Blender (Файл → Импорт → glTF 2.0), Godot, Unity (glTFast) и в онлайн-просмотрщиках.

## Как пересобрать

```bash
npm install
npm run build        # рендеры + pixel-mech.glb
npm run renders      # только картинки
node tools/build.mjs --view=front,three4   # отдельные ракурсы
```

Нужен Chromium: скрипт берёт его из `CHROME_PATH`, `PLAYWRIGHT_BROWSERS_PATH` или обычной установки Playwright.

## Устройство модели

Масштаб: шаг шипа 0.8, пол — `y = 0`, лицом к `+z`. Высота до шипов рожек пришельца — 28.

Каждая деталь — воксельная сетка со своим шагом клетки. Видимые клетки превращаются в кирпичи 1×1…1×6 с перевязкой рядов, фаской и небольшим разбросом тона. Клетка может быть скосом: коробка, отсечённая плоскостями, — так сделаны срезанные углы кулаков, скруглённая кромка ступней, верх шапки и боковых плит. За каждым кирпичом стоит тёмная подложка, поэтому швы читаются как настоящие зазоры. Затенение в углах (AO) запекается в цвета вершин по заполненности соседних клеток — только внутри детали, чтобы в разобранном виде ничего не пачкалось. Шипы точёные, в том числе боковые. Техник-втулки, штифты, болты-оси, шея, очки и магнитные шайбы на стыках — отдельная геометрия.

| Узел | Деталь | Как сделано |
|---|---|---|
| `shapka` | шапка-череп | два ряда белой кладки с шипами, верхний со скосами по краям и тёмным скосом сзади; пришелец 8×6 из фиолетовых плиток, рожки выше тела, глазницы — утопленные чёрные плитки |
| `ochki` | очки | щиток по дуге головы, выпуклый по вертикали, вырез переносицы, тонировка с градиентом к верху, оправа-бровь, петли с винтом, дужки к шарниру на плите |
| `lico` | лицевая панель | жёлтая кладка тонкими рядами (0.48), нижний ряд утоплен; глаза и 8-битный рот — отдельные чёрные плитки (для мимики) |
| `bokL`, `bokR` | боковые плиты | толщина 1.25 шипа, столбики боковых шипов, два шипа вперёд на торце, техник-кирпич с двумя отверстиями, оранжевое ухо сзади, скруглённый верх |
| `sheya` | шея-штырь | воронёный ПВХ: воротник с пятью винтами, штырь с канавкой и нижним пояском |
| `korpus` | корпус | таз со скошенными углами и техник-отверстиями, двухцветный пояс, грудь из макро-блоков с 8 крупными шипами и белой серединой, верхний ряд с шипами, тёмные плечевые колодки, светлые оси |
| `rukaL`, `rukaR` | руки | тёмное плечо со скосом и осью сверху; кулак-блок 4×5×4 из макро-блоков со скосами на углах и тёмными костяшками; поза подобрана по силуэту листа |
| `nogaL`, `nogaR` | ноги | бедро тонкими рядами, оси в тазовом и коленном узлах, голень мелкой кладкой с наклоном |
| `stupnyaL`, `stupnyaR` | ступни | 7×13: основание (высокие кирпичи по центру, плиты по бокам), средний ярус из плит, верхний со скруглённой кромкой, вилка-кронштейн, четыре болта |

Материалы в GLB: `abs_plastic` (матовый, цвета вершин), `black_tile`, `gunmetal`, `sunglass_lens` (прозрачный, с градиентом), `sunglass_frame`. Во вьювере линза рисуется как тонировка умножением плюс зеркальные блики — глаза видны сквозь красный, как на листе.
