# Форма с картинки → кирпичи (инструменты к docs/FORMA-INSTRUMENTY.md)

Числа формы на глаз больше не задаются: форму считает картинка. Результат включается флагами — по умолчанию
модель не меняется до «одобряю».

## Голова по листу с ракурсами (`--opt=golova=list`)

1. `list.py лист.png папка/ --nn isnet-general-use.onnx` — виды листа (спереди, слева, сзади, справа, 3/4):
   - маски вырезаются нейросетью: белое на светлом фоне по цвету не отделить;
   - голова отделяется от подставки по шее.
   Модель: https://github.com/danielgatis/rembg/releases/download/v0.0.0/isnet-general-use.onnx
2. `obolochka.py папка/ src/plus-forma.js` — объём по силуэтам видов прямо в сетке шипов, сечения в плане —
   суперэллипс (показатель подбирается по виду 3/4). Цвет клетки — с вида, куда она смотрит. Рамка красного
   козырька — замер для прозрачной линзы.
3. `metrika.py папка/ renders/` — совпадение силуэтов рендера и листа (IoU) по видам, рамка к рамке.

## Обувь по одной картинке (`--opt=obuv=piccolo`)

1. Вырезка сапога с картинки по цвету (замша и неон), отправка в генератор 3D Hunyuan3D-2.1
   (`gradio_client`, `/shape_generation`, токен `HF_TOKEN`). Генератор может слепить пару — берётся крупный кусок.
2. `kirpichi.py сапог.glb сапог-rgba.png src/plus-sapog.js --global PixelMechSapog --setka 16000`:
   - сетка в размерах Плюса (длина 8.4);
   - кирпичи полшипа и гладкая литая поверхность, цвет по картинке (неон / замша);
   - чужой логотип не переносится.
   Сборка берёт литую поверхность; `--opt=sapogKirpichi=1` — кирпичи.

`glb-vid.mjs` (в `tools/zver/`) — осмотр любой GLB с разных сторон.
