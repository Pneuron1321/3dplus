# Квота генератора 3D кончилась — что можно сейчас (Трезубец + Глубокий Транзитор, 24.10)

Факт: все генераторы 3D на Hugging Face работают на общей бесплатной квоте ZeroGPU (`zero-a10g`): Hunyuan3D-2 /
2.1 / mini, TRELLIS, InstantMesh, TripoSG, MoGe. Квота на весь аккаунт, а не на отдельный Space, поэтому смена
Space не помогает. У моделей 3D нет платных «провайдеров вывода» на HF (`inferenceProviderMapping` пуст).
Аккаунт без Pro.

## Ψ · Трезубец

**Ось.** Голова Плюса получает чистые цвета деталей сегодня, без ожидания квоты.

**Засечки.** Ждать 21 час; купить Pro; искать другой бесплатный Space.

**Карта.** Шов: «цвет даёт только генератор» ↔ «цвет есть на самом листе». Избыток: форма головы уже есть и
очень похожа (так сказал Александр). SAM2 теперь скачивается и работает локально. У кирпичной фигурки цвет
плоский: одна деталь — один цвет.

**Зубья.**
1. **Цвет по деталям, а не по точкам.** SAM2 вырезает на листе каждую деталь: козырёк, лицо, пришельца, купол,
   уши-рамки, диски. Сетка головы делится на детали по форме. Каждой детали достаётся один чистый цвет палитры.
   Так красят профи: заливкой по детали, без «грязи».
   *Дыра:* сетку надо разделить на детали; для кирпичной головы это получается по резким рёбрам и по положению.
2. **Свой GPU на время.** Дублировать Space на свою видеокарту Hugging Face (≈ 0,4–1 $ в час, нужна карта
   оплаты) — генератор вместе с текстурой без лимита, пока включено.
3. **Другие сервисы с API.** fal.ai, Replicate, Tripo, Meshy (≈ 0,1–0,5 $ за модель, нужен ключ и домен в сети).
4. **HF Pro** (9 $ в месяц): квота ZeroGPU в 8 раз больше, хватает на несколько раскрасок в день.
