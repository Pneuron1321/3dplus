# Плюс в 3D — план на настоящую точность (30.10)

Александр: «модель, построенная по форме, — вообще даже не близко»; «разузнай инструменты, чтобы считать форму даже с
AI-картинки». Прогон: Глубокий Транзитор → Фарватер ∿ → Отмычка ⚿.

## 0. Честно: почему мои пробы мимо
- **Генератор (Hunyuan3D-2.1)** — «пудинг»: форма в сетке 256³ на всю фигуру, кирпичик и шип меньше шага сетки;
  главная картинка была «3/4» с поворотом 10° — глубину взять неоткуда, боковые виды почти не учтены.
- **Моя сборка из коробок** — я снял только рамки деталей (ширина, высота, глубина). Плечи, предплечья, тапки, шлем на
  картинке — скруглённые, из многих сегментов; коробка их не передаёт. Это каркас, не форма.
- **Сами 5 видов не согласованы**: сбоку ноги на ~140 точек ниже, чем спереди; сзади руки ближе к телу (ширина/рост
  0,49 против 0,55); сбоку фигура на 2,7 % выше. Совпасть сразу со всеми пятью нельзя — главный вид нужно выбрать
  (спереди), остальные — подгонять по частям.

- **Итог по сборке из коробок (30.10):** Александр остановил — «форма ещё дальше от прошлых». Путь закрыт;
  sborka.py остаётся только как раскладка мест деталей по виду спереди.

## 1. Транзитор по ограничениям
| Ограничение | Тип | Чтение |
|---|---|---|
| Quest ≤ 10 тыс. треуг., ≤ 10 МБ; ПК ≤ 70 тыс. | твёрдое | держим: высокая сетка — только как источник карт рельефа |
| Виды AI и между собой не согласованы | стандарт | реальность: главный — спереди, остальные по частям |
| «Форму должен считать генератор по всей фигуре сразу» | **тень** | это реализация; боль — точная форма |
| Бесплатно 4,5 мин GPU в день (HF ZeroGPU) | **тень** | PRO $9/мес = 40 мин/день; платные API — центы за модель |
| Нет своей видеокарты | стандарт | облачные генераторы и Spaces |
| «Картинок ровно 5» | **тень** | Александр рисует любой нужный вид за минуту — это избыток |

## 2. Избыток (что уже есть даром)
1. 5 чётких видов 1086×1448 — главное богатство; вид спереди точный.
2. Раскладка деталей по высоте и ширине с вида спереди (sborka.py) — места деталей верные, неверна их форма.
3. Своя проекция краски (proekciya.py) — краска ложится точно, когда форма совпадает с видом.
4. Генератор картинок у Александра — новые виды (крупно часть, вид сверху, настоящий 3/4) почти бесплатно.
5. Blender без окна, xatlas, scipy — запекание и упрощение.

## 4. Семь отмычек
- **Время** — копить прогоны: квота в день, перебор семян ночью, выбирать лучший. *Слабо одно, но в синтез.*
- **Площадь** — **генерировать не фигуру, а детали**: голова отдельно, тапок отдельно, рука, нога. Тот же генератор
  отдаёт всю свою сетку одной детали → резкость в 3–5 раз выше. Виды деталей — вырезы из 5 видов (голова ~360 px)
  или новые крупные виды от Александра (каждая деталь на весь кадр, 4 стороны).
- **Повтор** — Tripo Multiview / Rodin уже умеют ровно «4 вида → форма»; платить центы вместо недель своей работы.
- **Рецепт** — форма как рецепт: sborka.py с параметрами, которые **подбираются сами** под силуэты всех видов
  (анализ через синтез), а не руками по рамкам.
- **Слой ниже** — Плюс и есть кирпичи: форма на сетке шипов (шаг кирпича) — грани точёные по построению; краска на
  кирпич — с видов. Для Quest — упрощение и запекание карт.
- **Инверсия** — не подгонять форму под несогласованные виды, а **виды под форму**: отрендерить готовую 3D-форму с
  4 сторон и попросить генератор картинок перекрасить рендер «в кирпичный Плюс» (img2img) — новые виды согласованы
  с формой по построению, краска ложится без пятен.
- **Ноль** — в VRChat на расстоянии видны силуэт и краска, мелкий рельеф — картой нормалей. Точная геометрия
  каждого шипа не нужна (и в 10 тыс. не влезет).

## 5. Фарватер (Z — польза, X — цена/риск, отделяются ли)
| Идея | Z | X (слой) | Итог |
|---|---|---|---|
| Площадь: по деталям | резкость ×3–5, детали отдельно под кости | сборка стыков; 5–8 прогонов (квота/деньги) | **берём** |
| Повтор: Tripo Multiview | 4 вида ровно наши, чистые твёрдые формы | деньги, ключ API, данные уходят во внешний сервис | **берём на пробу** |
| Hi3D дотачивает | убирает пудинг с любой формы | открытый, ещё молодой | **берём вторым шагом** |
| Рецепт с автоподбором | точное совпадение силуэтов | неделя работы, формы всё равно грубые | отбой как основной; кусками — для мест деталей |
| Слой ниже: кирпичи | точёность по построению | уже было (v6) — «ступени», мимо формы | отбой как основной |
| Инверсия: виды под форму | краска без пятен навсегда | нужны картинки Александра ещё раз | **берём на краску** |
| Ноль | бюджет Quest | — | правило: высокая сетка → карты |

Сумма: ни одна идея не тащит прежнюю ошибку («одна сетка на всю фигуру» и «коробки»).

## 6. Синтез — одно решение
**Форма считается по деталям лучшим генератором, дотачивается, собирается по раскладке вида спереди, краска — с видов,
согласованных с формой.**
1. **Проба (вечер, может провалиться): только голова.** Вырезать голову из 4 видов (спереди, слева, сзади, справа),
   увеличить до 1024, прогнать: (а) Tripo H3.1 Multiview, (б) Hunyuan3D-2.1 с сеткой 512, (в) Direct3D-S2 по виду
   спереди. Сравнить резкость визора, наушников, шлема рядом с картинкой. Мерило — наложение силуэтов (IoU ≥ 0,95)
   и глаз Александра.
2. Лучший способ — на остальные детали: грудь с тазом, плечо, предплечье с кистью, бедро, голень, тапок. Каждую — с её
   вырезов или с новых крупных видов.
3. Hi3D — дотачивает каждую деталь.
4. Сборка: места и размеры — по виду спереди (sborka.py уже знает), глубина — по боковому.
5. Краска: proekciya по каждой детали отдельно; если пятна — «инверсия»: рендеры деталей → Александр перекрашивает
   в генераторе картинок → проекция.
6. Quest/ПК: упрощение до 10/70 тыс., запекание карт цвета и нормалей с высокой сетки.

**Цена:** HF PRO $9/мес или ключ fal.ai (Tripo) — центы–$0,5 за деталь, ~10 деталей. **Откат:** plus-hy21.glb и
сборка остаются; ничего не стирается. **Δ** против прошлого: детали в 3–5 раз резче, форма — не пудинг и не коробки.
