# Как стать скульптором и моделистом уровня топ-профессионалов — Глубокий Транзитор (24.10)

Отзыв Александра:
- **сапоги** вырезаны и считаны чётко, но поставлены неправильно: слишком маленькие, непропорциональные;
- **голова** не считана: реальное совпадение меньше 30 %, хотя моя метрика показала 85–88 %.

Задание: разобраться, какие инструменты сделают меня скульптором и моделистом, который считывает форму с картинки
и строит модель на уровне мировых топов.

## Главный вывод: моя мера врала

Метрика «силуэт к силуэту, рамка к рамке» дала 88 %, а глаз Александра видит меньше 30 %. Силуэт круглой головы
похож на силуэт любой круглой головы. Узнаётся же голова по **деталям и их местам**: козырёк, уши, пришелец,
лицо, их размеры и пропорции. Я мерила не то, на что смотрят. Это стена номер один: пока мера врёт, любой
инструмент будет «улучшать» не то.

## Как работает топ-профессионал (и чего нет у меня)

| Этап у профи | Что делает | Что было у меня |
|---|---|---|
| Доска референсов | чистые ортогональные виды, одна камера, без подписей, крупно | лист 1254 × 365 с линейками, ~200 точек на вид |
| Пропорции | сначала замеряет отношения частей (голова : тело, стопа : голень) | ставила деталь в старое место старого размера → сапоги маленькие |
| Болванка (blockout) | крупные формы из примитивов **в настоящем 3D-редакторе**, сверка с видами наложением | свои формулы и воксели в JS |
| Вторичные формы | детали по частям: козырёк, уши, пришелец — каждая своей формой | всё одной оболочкой, детали растворились |
| Сверка | наложение рендера на референс полупрозрачно, по деталям | один процент по силуэту |
| Финал | топология, развёртка, текстура, вращение кругом | — |

## Ψ · Глубокий Транзитор — стены и маршруты

| Стена | Тип | Маршрут |
|---|---|---|
| Мера по силуэту | **ложная** (мерила не то) | мера **по деталям**: маска каждой детали на референсе и на рендере (козырёк, лицо, уши, пришелец, купол), IoU каждой + положение и размер центра; плюс наложение рендера на референс 50 % — показывать Александру его, а не проценты |
| «Нет 3D-редактора» | **ложная** | Blender как библиотека Python (`bpy` с PyPI) уже доступен: примитивы, модификаторы (зеркало, скос, подразделение, булевы), изображения-подложки, рендер под камерой референса. Это инструмент профи, а не мои формулы |
| «Генератор видит только одну картинку» | **ложная** | у Hunyuan3D-2.1 есть вход **по видам**: спереди, сзади, слева, справа. Лист головы — ровно это. Я подавала одну картинку |
| Детали тонут в общей оболочке | настоящая | собирать **по частям**: каждая деталь — свой примитив (суперквадрик, цилиндр, бокс), подогнанный оптимизацией под её маски во всех видах |
| Разделение на детали | настоящая, решаемая | цвет-кластеры для кирпичных листов; SAM2 для сложных — веса с Hugging Face, нужен домен `*.hf.co` (сейчас CDN закрыт) |
| Масштаб на теле | настоящая | **лист пропорций** персонажа: отношения стопа : голень, голова : плечи с картинки → размеры детали в шипах до сборки. Сапоги «Пикколо»: длина ≈ 2,6 ширины голени, высота ≈ 0,5 длины |
| Грязный референс | настоящая, у Александра | чистый лист: 5–6 видов одной камерой, ортогонально, без подписей и линеек, ≥ 1024 точек на вид; если генерированный — тем же запросом |
| Мой глаз видит уменьшенное | настоящая | сверять кусками в полном размере (деталь к детали), а не весь лист разом |
| Квота генератора | снята | `HF_TOKEN` есть |

## Набор инструментов «моделиста»

1. **Пропорции** (`tools/forma/proporcii.py`): по картинке персонажа — отношения частей в цифрах и пересчёт
   в шипы Плюса до любой сборки.
2. **Генератор по видам**: Hunyuan3D-2.1 с `mv_image_front/back/left/right`, вход — чистые виды листа.
3. **Blender (`bpy`)**: болванка из примитивов по видам, подгонка, скосы, зеркало. Рендер под камерами листа,
   выгрузка в GLB для `pixel-mech.js` (или перевод в кирпичи).
4. **Детали по маскам**: цвет-кластеры или SAM2 → маска каждой детали во всех видах → примитив под неё.
5. **Мера по деталям и наложение**: IoU и сдвиг центра для каждой детали, полупрозрачное наложение
   «рендер поверх листа». Порог: каждая деталь ≥ 0,8, сдвиг ≤ 1 шипа.
6. **Кирпичизация**: литая поверхность → кирпичи только там, где это красиво. Обувь и органика могут быть литыми,
   как у настоящих фигурок.

## Что нужно от Александра

- Чистые референсы, как ты и собираешься прислать: сапоги, руки, ноги. Лучше — лист с видами одной камерой без подписей.
- По возможности одна картинка всего Плюса целиком — для пропорций (размер сапог относительно ног).
- В разрешённые домены окружения добавить `*.hf.co` — чтобы скачивать веса моделей (SAM2 и др.), а не только звать Spaces.

## Порядок, когда придут картинки

1. Пропорции → размеры в шипах.
2. Генератор по видам (если видов несколько) или по одной картинке (обувь).
3. Деталь в Blender: чистка, масштаб, посадка на ногу или руку.
4. Мера по деталям и наложение → показать Александру наложение, а не проценты.
