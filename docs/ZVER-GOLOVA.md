# Голова «зверя» — органическая лепка по листу Александра (23.10.2026)

Просьба Александра: «Голову монстра не нужно делать из стиля Плюса. Дословно разработай для него голову из моего
изображения» (лист зелёного громилы: FRONT, SIDE, MOUTH & TEETH, CREST / SPINES).

## Почему раньше выходили кубики
Генератор `src/pixel-mech.js` строит всё из вокселей-кирпичей (`Vox`, шаг 0.8 × 0.512 × 0.8). Любая форма на нём —
ступенчатая, поэтому прежние «звери» были набором кубов. Для монстра метод заменён.

## Метод
`src/zver-golova.js` (подключается в `tools/render.html` и `index.html` перед `pixel-mech.js`; `opts.lico = 'zver'`):
- **Кожа — неявная поверхность** (поле расстояний): анатомические формы слиты плавным объединением, лишнее вырезано
  плавным вычитанием. Сетка — «surface nets» по решётке 0.085 (облегчённо 0.16), сначала грубый проход, точный — только
  у поверхности. Нормали — градиент поля, тени складок — затенение по полю (AO), фактура — шум.
- **Части (у каждой своя форма):** череп (лоб скошен), лицевая масса, морда, скулы, брыли, нижняя челюсть, подбородок,
  надбровья (злой излом, нависают над глазами), переносица, нос с крыльями и ноздрями, губы-валики, острые уши со
  впадиной, шея, узкие глазницы, складки (лоб, между бровей, переносица, под глазами, носогубные, подбородок).
- **Пасть — настоящая полость** (вычитание), внутри тёмная, дёсны у края, язык с бороздой.
- **Зубы** — изогнутые конусы: верхний ряд (10) с клыками, нижний (9) с бивнями по краям, второй ряд глубже (8);
  корни — у края полости за губой (край ищется по полю).
- **Глаза** — светящиеся шары: жёлто-оранжевая радужка, красная кромка, тёмный зрачок; моргают (мимика модели).
- **Гребень и грива** — шипы-перья по поверхности черепа (точки — лучами из центра до кожи): основание, сплющенное
  сечение, изгиб назад, острие, светлая жилка и тёмные края; гребень от лба назад, грива по бокам, бородка, затылок.
- **Контур** как на рисунке — тёмная оболочка изнанкой (кожа и шипы).

## Проверка
`node tools/build.mjs --lico=zver --view=zlist` → `renders/zfront|zside|z34-zver.png` (сверка с листом: спереди,
сбоку, 3/4); `--opt=bezShipov=1` — лепка без шипов. Голова на теле — `renders/hero-zver.png`, модель —
`pixel-mech-zver.glb`.

## Что пока приближение
- Шипы — гладкие перья, а не «пряди» с внутренней штриховкой рисунка; кромка гребня у лба шире, чем на листе.
- Морщины — бороздки-капсулы, мелкой рельефной кожи (как штрихи на рисунке) нет.
- Пасть раскрыта статично — челюсть не двигается при речи.
- Шея — короткая под робота; массивной шеи-трапеции с листа нет (тело — робот Плюса).
- Цвет — по вершинам, без текстур.

## Форма из рисунка (23.10, по решению «форма важна») — теперь по умолчанию

После Трезубца (docs/ZVER-TREZUBETS.md) голова строится не из моих форм, а из самого рисунка:
- `src/zver-risunok.js` — вырезка зверя с листа спереди и сбоку (RGBA) и поле расстояний до силуэта каждого вида
  (генерируется скриптом из `docs/maket/ref-zver-list.jpg`; шея и плечо в профиле срезаны наискось).
- Объём: точка внутри, если она внутри силуэта спереди **и** сбоку, и в своём сечении — внутри суперэллипса
  «ширина спереди × глубина сбоку» (края сглажены по высоте — без ступенек). Гребень берёт шипы по силуэту спереди,
  глубину — по огибающей профиля. Тёмное на рисунке (пасть, складки, глазницы) утоплено внутрь.
- Цвет: рисунок спереди проецируется на всё, что смотрит вперёд, профиль — на бока (зеркально на левую сторону);
  морда профиля на боковину головы не кладётся. Тонкий тёмный контур — как обводка.
- Прежняя лепка из форм — `--opt=lepka=1`.

Что получилось: спереди и в 3/4 — рисунок в объёме, силуэт совпадает с листом в обоих видах.
Что пока приближение: чистый профиль (90°) — морда сбоку смазана проекцией фронта; гребень в повороте — массой, а
не отдельными шипами (шипы спереди и сбоку на листе не совпадают в пространстве); сзади — догадка по профилю;
GLB ≈ 16 МБ (плотная сетка + контур). Следующий шаг по разбору — генератор 3D по картинке (TRELLIS): нужен доступ
контейнера к huggingface.co и *.hf.space.

### Второй рисунок (23.10, «этот мне больше нравится», «лицо шире»)
Фронт теперь — крупный план зелёного монстра из комикса (`docs/maket/ref-zver-2.jpg` в закрытом репо): голова
вырезана целиком (фон — бежевый и красное кольцо — убран по цвету), раздвинута по ширине ×1,25, центр — по подбородку.
Профиля у этого рисунка нет — глубина и бока пока с прежнего листа (вид сбоку — от старого зверя). Данные —
`src/zver-risunok.js` (U = 0.038, глаз→подбородок 157,5 точки).
