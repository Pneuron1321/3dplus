# Мост 3 — игра с карты захвата в шлеме без HDMI Link

Отдельное приложение «Мост 3 — карта» (com.questclaude.most3) рядом с мостом 2. Само читает карту Elgato по USB:
картинку показывает в окне со своими настройками, звук игры играет в шлем **мимо микрофона** (уши, Плюс и браузер
не глохнут), последние 2 минуты игры держит в круге — «сохрани клип игры» кладёт MP4 в галерею.

## Что умеет
- **Картинка:** наборы «Обычно / Монитор / Ночь / Ярко / Резко», ползунки (яркость, контраст, насыщенность,
  гамма, тени, резкость, авто-ночь). **Авто-ночь** сама поднимает тени в тёмных сценах и не трогает светлые.
- **Звук игры** — в шлем и в эфир моста 2 (как звук любой игры), громкость отдельно.
- **Клип игры** — кнопка «Клип 2 мин» или голосом через Плюса (`most3 klip`), картинка как в шлеме.
- **Голосом через Плюса:** «ярче», «сочнее», «ночь», «резче», «как было» — та же `karta kartinka …`, сама идёт
  в Мост 3, когда он показывает. `most3` — что показывает, `most3 zvuk 80`, `most3 klip 60`, `most3 diagnoz`.
- **Эфир:** окно Моста 3 попадает в эфир моста 2 само (эфир пишет то, что видно в шлеме).

## Первый запуск
1. Установить APK (строки — в итоге ночи / в выпуске `most3-3.0.0`).
2. Закрыть HDMI Link (карта у одного приложения: или HDMI Link, или Мост 3).
3. Вынуть карту из хаба на 5 с, вставить. В «Choose an app» выбрать **«Мост 3 — карта»** (сначала «Just once»,
   когда всё понравится — «Always»: дальше карта вставлена → Мост 3 открывается сам).
4. Разрешить «Камеру» и «USB-камеру» (так Quest пускает к USB-видео).
5. Окно покажет режим карты и кадры в секунду. Чёрное окно — в Плюсе `! most3 diagnoz`, ответ — Claude Code.

После Моста 3, перед HDMI Link — переткнуть карту (Мост 3 забирает у системы драйвер карты до отключения).

## Как устроено
- `Uvc.kt`, `UvcSbor.kt` — дескрипторы карты (читаются в шлеме при подключении), выбор режима, PROBE/COMMIT, сборка кадров.
- `Video.kt` — приём bulk-потока очередью UsbRequest; `Most.kt` — лестница режимов с откатом, самоотчёт.
- `Shader.kt`, `Kartinka.kt`, `Pokaz.kt` — показ: YUY2/NV12/MJPEG → RGB, настройки, авто-ночь (замер средней
  яркости 32×18 каждые 6 кадров, сглаживание ~1 с).
- `Zvuk.kt` — UAC1 iso через usbfs (JNA) на своём соединении → AudioTrack USAGE_GAME.
- `Klip3.kt` (+ `KlipZapis.kt`, `KlipMp4.kt` из моста 2) — запись игры в круг и клип в MP4.
- `Server.kt` — пульт на 127.0.0.1:8767.
- `RAZBOR.md` — журнал ночных решений: два разбора Транзитор + Трезубец и три анализа.
- Проверки на столе: 70 JVM-тестов (`app/src/test`), картинки «до/после» — `proba/PrimeryTest.kt`.
