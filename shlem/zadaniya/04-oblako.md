Плюс, это задание от Claude Code из чата Александра, он разрешил выполнить.
Читай через `curl -fsSL`.

Итог задания 03: Whisper small в шлеме — 10–16 с на фразу и ошибки, до
уровня диктовки не дотягивает; large-v3-turbo в 4 раза медленнее —
бессмысленно. Решение: фраза после «плюс плюс» идёт в Groq (облачный
Whisper large-v3, ~1 с, бесплатно), если в шлеме есть ключ; нет ключа или
сети — как раньше, локальная small. Ключ Александр кладёт сам командой
`kluch`. **Ключ — секрет: /root/.groq-key не читай, не печатай, не
произноси, ни в какие команды с выводом его не вставляй.**

## 1. Останови sluh-test

```
grep -E "^==|среднем" /tmp/sluh-test.log
pkill -f '[s]luh-test'
du -sh /root/.cache/huggingface/hub/models--*large-v3-turbo* 2>/dev/null
```

Скажи одной фразой, что успел показать тест. Если large-v3-turbo скачана —
удали её папку (это ~1,6 ГБ, она не нужна).

## 2. Новые файлы

```
B=https://raw.githubusercontent.com/Pneuron1321/3dplus/36099fe1d6c3e58e9b0a1d85f413cec74539539a/shlem
cd /usr/local/bin
for f in ushi sluh kluch; do curl -fsSL "$B/$f" -o "$f" || echo "НЕ СКАЧАЛСЯ $f"; done
chmod +x kluch
python3 -c "import ast,sys; [ast.parse(open(f).read()) for f in sys.argv[1:]]" ushi sluh && sh -n kluch && echo OK
echo 2 > /root/.ushi-pauza
```

Через ~15 с: `tail -4 /tmp/ushi.log` — должны быть «обновлены — перезапуск»
и «слух: готов». Если перезапуска нет (работают старые уши) — попроси
Александра вставить строку перезапуска из чата. `.ushi-pauza` — тишина конца
фразы 2 с; заработает с приложением 0.3.7, на старом просто ничего не делает.

## 3. Ключ Groq — делает Александр

знак kluch». `kluch` сам скажет: «работает», «не принял» (401) или «отказал»
(403 — возможно, страна недоступна). Передай Александру, что он написал.

## 4. Проверка

Попроси сказать «плюс плюс» и фразу подлиннее. Реплику «(голосом) …» не
выполняй — это проверка. `grep whisper /tmp/ushi.log | tail -1`: ждём
`whisper groq N с`. Скажи одной фразой: что распознано и за сколько секунд.
`whisper local` — облако не ответило; причина — в `tail -3 /tmp/sluh.log`
(там только код ошибки, ключа там нет).
