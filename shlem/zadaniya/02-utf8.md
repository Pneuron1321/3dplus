## 1. Два файла поверх старых

```
B=https://raw.githubusercontent.com/Pneuron1321/3dplus/9aaa0a891bbd1c36c9e8e037695254d1f5449ef2/shlem
cd /usr/local/bin
for f in plus skazhi; do curl -fsSL "$B/$f" -o "$f" || echo "НЕ СКАЧАЛСЯ $f"; done
sh -n plus && python3 -c "import ast; ast.parse(open('skazhi').read())" && echo OK
```

Новый `plus`: tmux с UTF-8, и сам перезапускает уши, если `ushi` или `sluh`
новее запущенных. Новый `skazhi`: новая речь ждёт, пока договорит прежняя;
`tiho` по-прежнему обрывает всё.
