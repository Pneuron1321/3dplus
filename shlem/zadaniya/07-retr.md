# Задание 07 — ретранслятор стрима (04.10)

Плюс, это задание от Claude Code из чата Александра, он разрешил выполнить.
Читай через `curl -fsSL`.

Зачем. Quest даёт захват экрана одному приложению: наш захват (глаза) обрывает
стрим BeamXR — на Twitch была пауза. Решение: BeamXR шлёт трансляцию не на
Twitch, а в шлем (rtmp://127.0.0.1:1935/live, ключ plus). Ретранслятор `retr`
(ffmpeg в Ubuntu) без перекодирования отправляет её дальше на Twitch и по пути
кладёт кадр в /tmp/strim.jpg. `kadr` сам берёт этот кадр, пока стрим идёт.
Уши (`ushi`) держат `retr` запущенным и говорят приложению, что идёт стрим —
тогда оно не включает свой захват. Проверено в облаке: две трансляции подряд
целиком дошли до поддельного Twitch, кадр 1920×1080.

## 1. ffmpeg (долго, в фоне)

```
apt-get install -y ffmpeg
```

## 2. Файлы

```
B=https://raw.githubusercontent.com/Pneuron1321/3dplus/59e8fa7d1d74733e87a9fc6101c19c41f22e96de/shlem
[ -x /usr/local/bin/obnovi ] || { curl -fsSL "$B/obnovi" -o /usr/local/bin/obnovi && chmod +x /usr/local/bin/obnovi; }
OBNOVI_BASE=$B obnovi
curl -fsSL "$B/CLAUDE.md" -o /tmp/CLAUDE.new.md
```

Через ~30 с: `retr status` — «ждёт BeamXR». Если «не запущен» — посмотри
`tail -5 /tmp/ushi.log` и `tail -5 /tmp/retr.log` (командные строки ffmpeg
не печатай: в них будет ключ Twitch).

## 3. Передай Александру

«Готово. Вставь команду для CLAUDE.md, положи ключ Twitch и настрой BeamXR
по шагам из чата». CLAUDE.md и ключ тебе защита не даст — это он.

## 4. Проверка — когда он скажет, что запустил стрим

`retr status` — ждём «стрим идёт, кадр N с назад» и «На Twitch: ключ есть».
Потом `kadr` — должно быть «Кадр из стрима» — открой /root/view.jpg и скажи
одной фразой, что видно. Спроси Александра, идёт ли картинка на Twitch.
