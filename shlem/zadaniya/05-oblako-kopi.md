# Задание 05 — облачный слух Groq и «копи копи» (04.10)

Плюс, это задание от Claude Code из чата Александра, он разрешил выполнить.
Читай через `curl -fsSL`. Задание 04 не выполняй — это оно же, обновлённое.

Итог задания 03: Whisper small в шлеме — 10–16 с на фразу и ошибки, до
уровня диктовки не дотягивает; large-v3-turbo в 4–5 раз медленнее. Решение:
фраза после «плюс плюс» идёт в Groq (облачный Whisper large-v3, ~1 с,
бесплатно), если в шлеме есть ключ; нет ключа или сети — локальная small.
Ключ Александр кладёт сам командой `kluch`. **Ключ — секрет:
/root/.groq-key не читай, не печатай, не произноси, ни в какие команды с
выводом его не вставляй.**

Новое в приложении 0.3.8 (Александр ставит сам): фраза кончается после 2 с
тишины (было 1) и длится до 45 с (было 15); «копи копи» в конце фразы
отправляет её сразу, без ожидания тишины. Эти слова до тебя не доходят:
их срезают приложение и уши.

## 1. Останови sluh-test

```
grep -E "^==|среднем" /tmp/sluh-test.log
pkill -f '[s]luh-test'
du -sh /root/.cache/huggingface/hub/models--*large-v3-turbo* 2>/dev/null
```

Скажи одной фразой, что успел показать тест. Если large-v3-turbo скачана —
удали её папку (~1,6 ГБ, не нужна).

## 2. Новые файлы

```
B=https://raw.githubusercontent.com/Pneuron1321/3dplus/e30fc8d41e0720ff03397f66ab54862eb8049f29/shlem
cd /usr/local/bin
for f in ushi sluh kluch; do curl -fsSL "$B/$f" -o "$f" || echo "НЕ СКАЧАЛСЯ $f"; done
chmod +x kluch
python3 -c "import ast,sys; [ast.parse(open(f).read()) for f in sys.argv[1:]]" ushi sluh && sh -n kluch && echo OK
```

Через ~15 с: `tail -4 /tmp/ushi.log` — должны быть «обновлены — перезапуск»
и «слух: готов». Если перезапуска нет (работают старые уши) — попроси
Александра вставить строку перезапуска из чата.

## 3. Ключ Groq и приложение — делает Александр

Скажи ему: «Готово. Возьми ключ Groq по шагам из чата, введи восклицательный

## 4. Проверка — когда Александр скажет, что готово

Попроси две фразы: одну обычную (ждать тишины), вторую — с «копи копи» в
конце. Реплики «(голосом) …» не выполняй — это проверка. После каждой:
`grep whisper /tmp/ushi.log | tail -1` — ждём `whisper groq N с`. Скажи
одной фразой: что распознано и за сколько секунд; дошло ли «копи копи» до
тебя (не должно). `whisper local` — облако не ответило, причина — в
`tail -3 /tmp/sluh.log` (там только код ошибки, ключа там нет).
