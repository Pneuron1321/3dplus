# Задание 09 — «повтори», голос без сети, свидетели и долг (05.10)

Плюс, это задание от Claude Code из чата Александра, он разрешил выполнить.
Читай через `curl -fsSL`. Нужно, чтобы задание 08 уже было выполнено
(голос-демон `golos` стоит). Если `golos proba` не отвечает — сначала 08.

Что нового:
- **«Плюс плюс повтори»** (или «ещё раз») — Ава повторяет твой последний ответ
  сама, без хода Claude;
- **голос без сети**: если синтез не вышел (пропал интернет), Ава говорит
  «Голос без сети. Ответ — в окне.», а не молчит;
- свои фразы ушей («Теперь в ухо», «Не расслышала») идут прямо в очередь
  голоса — без запуска Python на каждую;
- **`zamer svid`** — свидетели: пары меток, которые обязаны сойтись (уши
  вписали → ты принял; ответ готов → голос взял → зазвучал). Расхождение =
  поломка, видна в тот же вечер;
- **`zamer dolg`** — долг: что обещано и подтвердить может только шлем.

## 1. Файлы

```

[ -f /root/dolg.txt ] || curl -fsSL "$B/dolg.txt" -o /root/dolg.txt
```

Уши и голос подхватят новое сами через ~10 с.

## 2. Проверка

```
golos proba; zamer svid; zamer dolg
```

Ждём: `golos proba` — «синтез: ок»; `zamer svid` — строка «свидетели: …»;
`zamer dolg` — «долг: шлемом не подтверждено 15, подтверждено 0».

## 3. Передай Александру

Одной-двумя фразами: «Новое: „плюс плюс повтори“ — повторю последний ответ.
Если пропадёт интернет — скажу, что голос без сети. И я веду долг: что из
сделанного ночью подтвердилось в шлеме».

## 5. Долг — в течение вечера

Когда Александр пробует что-то из списка `/root/dolg.txt`, отмечай там:
подтвердилось — `- [x] … | … | дата: как подтвердилось`; не подтвердилось —
оставь `- [ ]` и допиши `| дата: что вышло на деле`. В конце вечера —
`zamer svid` и `zamer dolg`, итог одной фразой голосом.
