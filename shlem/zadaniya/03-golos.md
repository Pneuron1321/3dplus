## 3. Сравнение моделей и потоков (в фоне, долго)

```
/opt/sluh/bin/python /usr/local/bin/sluh-test small large-v3-turbo > /tmp/sluh-test.log 2>&1
```

large-v3-turbo при первом запуске скачивается (~1,6 ГБ). Если `nproc`
больше 4 — потом ещё small с потоками по числу ядер:

```
SLUH_THREADS=$(nproc) /opt/sluh/bin/python /usr/local/bin/sluh-test small > /tmp/sluh-test-t.log 2>&1
```

Скажи Александру: среднее время каждой модели (и small с другими потоками),
тексты, где модели разошлись; спроси, где точнее. Выбор ставится файлом,
уши подхватят сами через несколько секунд:

```
echo large-v3-turbo > /root/.sluh-model     # только по его «да»
echo 6 > /root/.sluh-threads                # если с потоками быстрее
```
