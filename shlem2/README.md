# Плюс — версия 2

Файлы второй версии для шлема. Первая версия (1.0) — в папке `shlem`, она не
меняется: её «обнови» берёт файлы только оттуда.

Вторая версия живёт рядом с первой:
- приложение **Quest Claude Bridge 2** (`com.questclaude.bridge2`, порт 8766);
- своя Ubuntu **plus2** в том же Termux — копия Ubuntu 1.0 (`termux/ustanovka-plus2`);
- вход в Claude общий с 1.0 (`termux/plus2` подключает файл входа первой Ubuntu);
- запускать по очереди: микрофон и захват держит одно приложение.
