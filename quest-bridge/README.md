# Quest Claude Bridge 2 — приложение для шлема

Android-приложение для Meta Quest 3: захват экрана и звука, эфир на Twitch, Плюс в кадре (лицо, плечи,
чат, роза ветров, мини-плеер музыки), камера айфона, уши (Vosk) и HTTP-сервер на 127.0.0.1:8766 для скриптов
шлема (`../shlem2`).

- Собирается здесь, в GitHub Actions (`.github/workflows/prilozhenie.yml`); APK — в выпусках `app-<версия>`.
- Ключ подписи — только зашифрованный (`app/debug.keystore.enc`); пароль — секрет репозитория `PODPIS`.
  Один ключ на все сборки, чтобы обновление вставало поверх.
- Здесь копия; работа идёт в закрытом репозитории и переносится сюда целиком.

Собрать заново без изменений кода — Actions → prilozhenie → Run workflow (ветка claude/tender-goodall-41rwsn).
